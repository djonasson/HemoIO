# Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the notes feature from `features/user-notes.feature`: note markers and measurement notes on the trend chart, a Notes view with search and filters, Markdown-subset formatting, and relative timestamps.

**Architecture:**
- Pure logic lives in small modules with their own tests:
  - `src/utils/relativeTime.ts`: minute-precision relative time
  - `src/utils/noteFormatting.ts`: toolbar text edits
  - `src/services/notes/`: Markdown subset parsing, search, filters, attachment labels
- UI:
  - `RelativeTime`: a focusable `<time>` with a full-date tooltip, shared with alerts
  - `NoteContent`: renders the parsed blocks as React elements; no HTML is ever parsed
  - a formatting toolbar in `NoteEditor`
  - focusable chart points that open a measurement dialog
  - a `NotesView` reached from a new nav item
- AppShell carries cross-view focus: a lab result to expand in Timeline, or a biomarker (and optional date) for Trends.

**Tech Stack:** React 19, Mantine 8 (`Spoiler`, `DatePickerInput`, `Modal`, `Tooltip`), Recharts 3, Dexie, Vitest + RTL, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-gherkin-completion-design.md`, section "3. Notes" (with the shared `formatRelativeTime` building block).

## Global Constraints

**Chart markers**
- A data point whose test value has notes gets a distinct marker: a ring plus a note glyph.
- Its accessible label gains `, has notes`.
- Hovering the point shows the chart tooltip, which previews the first note (newest first), cut to 120 characters.
- Keyboard users get the same preview in two ways:
  - Recharts 3's accessibility layer: focus the chart, and the arrow keys move the tooltip. The plan must not set `accessibilityLayer={false}`.
  - The focused point's SVG `<title>` gives screen readers the preview as its description.
  - Enter on a point opens its notes in full.

**Measurement notes**
- Data points are focusable buttons. Click, Enter or Space opens a dialog with the value, the date and an "Add Note" action.
- While adding, the dialog is headed `Note for {value} {unit} on {date}`, with date like `Jan 15, 2024`.
- Saved notes carry `testValueId`, `labResultId` and `biomarkerKey`.

**Notes view (a nav item "Notes", after Alerts)**
- Shows all notes, newest first.
- Each card shows what the note is attached to:
  - lab result: `{labName} · {date}`
  - biomarker: `{Biomarker}`
  - measurement: `{Biomarker} · {value} {unit} · {date}`
  - Clicking the label navigates there.
- Filters:
  - text search (`aria-label="Search notes"`)
  - date range (`aria-label="Notes from date"` / `"Notes to date"`; the end day is inclusive)
  - biomarker (`aria-label="Filter notes by biomarker"`)
  - tag (`aria-label="Filter notes by tag"`)
- Search matches are wrapped in `<mark>`.
- Filtering is client-side, after decryption.

**Formatting**
- A toolbar with `role="toolbar"` and `aria-label="Formatting"`.
- Buttons: `Bold`, `Italic`, `Bullet list`, `Numbered list`.
- Ctrl/Cmd+B and Ctrl/Cmd+I also work.
- Markdown subset: `**bold**`, `*italic*`, `- ` and `1. ` lists.
- An in-house renderer produces React elements. Unsupported syntax renders as text, and plain-text notes render unchanged.

**Timestamps**
- Relative: `just now`, `5 minutes ago`, `3 hours ago`, then the day-level wording of `formatRelativeTime` (`Yesterday`, `3 days ago`, `2 months ago`).
- The full date and time appear in a tooltip on hover, focus or touch.
- Edited notes show `(edited {relative})` the same way.

**Long notes**
- Collapsed to 120px behind a `Show full note` / `Show less` control.

**Never log note content** (health data).

## Review Focus

1. **Note text that looks like Markdown but is not** (`2*3*4`, a lone `**`, `Ferritin 30 ng/mL — taking iron & vitamin C (50%)`) renders exactly as typed, with no crash and no missing characters. Pinned in Task 3.
2. **A search term with regex characters** (`(50%)`, `c++`) filters and highlights without throwing. Pinned in Task 6.
3. **A note whose lab result or test value no longer exists** is still listed, with a fallback label, and does not crash the Notes view. Pinned in Task 6.
4. **A note created late on the "to" day** (18:00) is inside the date range. Pinned in Task 6.
5. **Formatting with nothing selected, or at the 5000-character limit:**
   - Bold with an empty selection inserts `****` and puts the cursor in the middle.
   - A format that would exceed the limit changes nothing.
   - Pinned in Task 4.

```ts
/**
 * When I navigate to the Notes view

export async function goToNotes(page: Page): Promise<Locator> {
  const nav = page.getByRole('navigation').getByRole('button', { name: /^Notes/ });
  await nav.click();
  await expect(nav).toHaveAttribute('aria-current', 'page');
  return page.getByRole('main');
}

/** The note cards of the Notes view */
export function noteCards(main: Locator): Locator {
  return main.getByRole('article', { name: /^Note attached to / });
}

/** A note's timestamp element, by the ISO date it represents */
export function noteTimestamp(container: Locator, iso: string): Locator {
  return container.locator(`time[datetime="${iso}"]`);
}
```

```ts
 * Like formatRelativeTime, but precise to the minute for the last day:
 * "just now", "5 minutes ago", "3 hours ago", then "Yesterday", "3 days ago"
 */
export function formatRelativeDateTime(date: Date, now: Date = new Date()): string {
  const minutes = Math.floor(Math.max(0, now.getTime() - date.getTime()) / 60_000);
  if (minutes < 1) return 'just now';
  if (minutes < 60) return `${minutes} ${minutes === 1 ? 'minute' : 'minutes'} ago`;
  const hours = Math.floor(minutes / 60);
  if (hours < 24) return `${hours} ${hours === 1 ? 'hour' : 'hours'} ago`;
  return formatRelativeTime(date, now);
}
```

```ts
/**
 * The Markdown subset notes are stored in: **bold**, *italic*, "- " and "1. "
 * lists. Anything else is text. Parsing yields data, never HTML.
 */

export interface InlineNode {
  type: 'text' | 'bold' | 'italic';
  text: string;
}

export type NoteBlock =
  | { type: 'paragraph'; lines: InlineNode[][] }
  | { type: 'bullet-list'; items: InlineNode[][] }
  | { type: 'ordered-list'; start: number; items: InlineNode[][] };

// Markers must hug their text, so "2 * 3 * 4" and a lone "**" stay text
const INLINE = /\*\*(\S(?:.*?\S)?)\*\*|\*(\S(?:.*?\S)?)\*/g;
const BULLET = /^- (.*)$/;
const ORDERED = /^(\d+)\. (.*)$/;

export function parseInline(text: string): InlineNode[] {
  const nodes: InlineNode[] = [];
  let last = 0;
  for (const match of text.matchAll(INLINE)) {
    if (match.index > last) nodes.push({ type: 'text', text: text.slice(last, match.index) });
    nodes.push(
      match[1] !== undefined ? { type: 'bold', text: match[1] } : { type: 'italic', text: match[2] }
    );
    last = match.index + match[0].length;
  }
  if (last < text.length) nodes.push({ type: 'text', text: text.slice(last) });
  return nodes;
}

export function parseNoteMarkdown(content: string): NoteBlock[] {
  const blocks: NoteBlock[] = [];
  for (const line of content.split('\n')) {
    const current = blocks[blocks.length - 1];
    const bullet = BULLET.exec(line);
    const ordered = ORDERED.exec(line);

    if (bullet) {
      if (current?.type === 'bullet-list') current.items.push(parseInline(bullet[1]));
      else blocks.push({ type: 'bullet-list', items: [parseInline(bullet[1])] });
    } else if (ordered) {
      if (current?.type === 'ordered-list') current.items.push(parseInline(ordered[2]));
      else blocks.push({ type: 'ordered-list', start: Number(ordered[1]), items: [parseInline(ordered[2])] });
    } else if (line.trim() === '') {
      // A blank line ends the paragraph; an empty placeholder keeps the next one separate
      if (current?.type === 'paragraph') blocks.push({ type: 'paragraph', lines: [] });
    } else if (current?.type === 'paragraph') {
      current.lines.push(parseInline(line));
    } else {
      blocks.push({ type: 'paragraph', lines: [parseInline(line)] });
    }
  }
  return blocks.filter((block) => block.type !== 'paragraph' || block.lines.length > 0);
}

function blockLines(block: NoteBlock): InlineNode[][] {
  return block.type === 'paragraph' ? block.lines : block.items;
}

export function toPlainText(content: string): string {
  return parseNoteMarkdown(content)
    .flatMap(blockLines)
    .map((line) => line.map((node) => node.text).join(''))
    .join('\n');
}

export function notePreview(content: string, max = 120): string {
  const flat = toPlainText(content).replace(/\s+/g, ' ').trim();
  if (flat.length <= max) return flat;
  const cut = flat.slice(0, max);
  const lastSpace = cut.lastIndexOf(' ');
  return `${(lastSpace > 0 ? cut.slice(0, lastSpace) : cut).trimEnd()}…`;
}
```

```ts
/**
 * Text edits behind the note editor's formatting toolbar
 */

export type NoteFormat = 'bold' | 'italic' | 'bullet-list' | 'numbered-list';

export interface TextEdit {
  text: string;
  selectionStart: number;
  selectionEnd: number;
}

const WRAP: Record<'bold' | 'italic', string> = { bold: '**', italic: '*' };

export function applyNoteFormat(text: string, start: number, end: number, format: NoteFormat): TextEdit {
  if (format === 'bold' || format === 'italic') {
    const marker = WRAP[format];
    return {
      text: text.slice(0, start) + marker + text.slice(start, end) + marker + text.slice(end),
      selectionStart: start + marker.length,
      selectionEnd: end + marker.length,
    };
  }

  // Whole lines the selection touches
  const lineStart = text.lastIndexOf('\n', start - 1) + 1;
  const nextBreak = text.indexOf('\n', end);
  const lineEnd = nextBreak === -1 ? text.length : nextBreak;
  const block = text
    .slice(lineStart, lineEnd)
    .split('\n')
    .map((line, i) => (format === 'bullet-list' ? `- ${line}` : `${i + 1}. ${line}`))
    .join('\n');

  return {
    text: text.slice(0, lineStart) + block + text.slice(lineEnd),
    selectionStart: lineStart,
    selectionEnd: lineStart + block.length,
  };
}
```

```ts
/**
 * Client-side note filtering: notes are only searchable after decryption
 */
import type { UserNote } from '@/types';
import { toPlainText } from './noteMarkdown';

export interface NoteListFilters {
  searchTerm?: string;
  startDate?: Date | null;
  endDate?: Date | null;
  biomarkerKey?: string | null;
  tag?: string | null;
}

function endOfDay(date: Date): number {
  const end = new Date(date);
  end.setHours(23, 59, 59, 999);
  return end.getTime();
}

export function filterNotes(notes: UserNote[], filters: NoteListFilters): UserNote[] {
  const term = filters.searchTerm?.trim().toLowerCase();
  return notes
    .filter((note) => {
      const created = note.createdAt.getTime();
      if (filters.startDate && created < filters.startDate.getTime()) return false;
      if (filters.endDate && created > endOfDay(filters.endDate)) return false;
      if (filters.biomarkerKey && note.biomarkerKey !== filters.biomarkerKey) return false;
      if (filters.tag && !note.tags.includes(filters.tag)) return false;
      if (term && !toPlainText(note.content).toLowerCase().includes(term)) return false;
      return true;
    })
    .sort((a, b) => b.createdAt.getTime() - a.createdAt.getTime());
}

export function splitForHighlight(
  text: string,
  term: string | undefined
): Array<{ text: string; match: boolean }> {
  const needle = term?.trim().toLowerCase();
  if (!needle) return [{ text, match: false }];

  const parts: Array<{ text: string; match: boolean }> = [];
  const haystack = text.toLowerCase();
  let from = 0;
  for (let at = haystack.indexOf(needle); at !== -1; at = haystack.indexOf(needle, from)) {
    if (at > from) parts.push({ text: text.slice(from, at), match: false });
    parts.push({ text: text.slice(at, at + needle.length), match: true });
    from = at + needle.length;
  }
  if (from < text.length) parts.push({ text: text.slice(from), match: false });
  return parts;
}
```

Plain `indexOf`, not a RegExp, so search terms are never patterns. Lower-casing can change length for a few non-ASCII characters (e.g. `İ`). Such a term simply may not highlight; filtering still works.

```ts
export type NoteAttachment =

  | { kind: 'biomarker'; label: string; biomarkerKey: string }

  testValues: ReadonlyMap<number, { value: number | string; unit: string; labResultId: number }>;

}

const DATE = new Intl.DateTimeFormat('en-US', { month: 'short', day: 'numeric', year: 'numeric' });

export function formatNoteDate(date: Date): string {
  return DATE.format(date);
}

export function describeNoteAttachment(note: UserNote, lookup: AttachmentLookup): NoteAttachment {
  if (note.biomarkerKey) {
    const name = lookup.biomarkerName(note.biomarkerKey);
    const testValue = note.testValueId !== undefined ? lookup.testValues.get(note.testValueId) : undefined;
    const result = testValue ? lookup.labResults.get(testValue.labResultId) : undefined;
    if (testValue && result) {
      return {
        kind: 'measurement',
        label: `${name} · ${testValue.value} ${testValue.unit} · ${formatNoteDate(result.date)}`,
        biomarkerKey: note.biomarkerKey,
        date: result.date,
      };
    }
    return { kind: 'biomarker', label: name, biomarkerKey: note.biomarkerKey };
  }

  if (note.labResultId !== undefined) {
    const result = lookup.labResults.get(note.labResultId);
    return result
      ? { kind: 'lab-result', label: `${result.labName} · ${formatNoteDate(result.date)}`, labResultId: note.labResultId }
      : { kind: 'none', label: 'Deleted lab result' };
  }

  return { kind: 'none', label: 'General note' };
}
```

```tsx
/**
 * The Notes view: every note, newest first, with search and filters.
 * Notes are decrypted when loaded, so all filtering happens here.
 */
import { useMemo, useState } from 'react';
import { Badge, Button, Center, Group, Loader, Paper, Select, SimpleGrid, Stack, Text, TextInput, Title } from '@mantine/core';
import { DatePickerInput } from '@mantine/dates';
import { IconNotes, IconSearch } from '@tabler/icons-react';
import { useNotes } from '@hooks/useNotes';
import { useLabResults } from '@hooks/useLabResults';
import { RelativeTime } from '@components/common/RelativeTime';
import { getBiomarkerByKey, getBiomarkerForTestValue } from '@data/biomarkers/dictionary';
import { describeNoteAttachment, filterNotes, type AttachmentLookup, type NoteAttachment } from '@services/notes';
import { NoteContent } from './NoteContent';

export interface NotesViewProps {
  onOpenLabResult: (labResultId: number) => void;
  onOpenTrend: (biomarkerKey: string, date?: Date) => void;
}

export function NotesView({ onOpenLabResult, onOpenTrend }: NotesViewProps): React.ReactNode {
  const { notes, isLoading, allTags } = useNotes();
  const { results } = useLabResults();
  const [searchTerm, setSearchTerm] = useState('');
  const [startDate, setStartDate] = useState<Date | null>(null);
  const [endDate, setEndDate] = useState<Date | null>(null);
  const [biomarkerKey, setBiomarkerKey] = useState<string | null>(null);
  const [tag, setTag] = useState<string | null>(null);

  const lookup = useMemo<AttachmentLookup>(() => {
    const labResults = new Map<number, { labName: string; date: Date }>();
    const testValues = new Map<number, { value: number | string; unit: string; labResultId: number }>();
    const names = new Map<string, string>();
    for (const result of results) {
      if (result.id !== undefined) labResults.set(result.id, { labName: result.labName, date: result.date });
      for (const tv of result.testValues) {
        if (tv.id !== undefined) testValues.set(tv.id, { value: tv.value, unit: tv.unit, labResultId: tv.labResultId });
        names.set(tv.biomarkerKey, getBiomarkerForTestValue(tv)?.name ?? tv.rawText ?? tv.biomarkerKey);
      }
    }
    return {
      labResults,
      testValues,
      biomarkerName: (key) => getBiomarkerByKey(key)?.name ?? names.get(key) ?? 'Unknown biomarker',
    };
  }, [results]);

  const biomarkerOptions = useMemo(() => {
    const keys = [...new Set(notes.flatMap((n) => (n.biomarkerKey ? [n.biomarkerKey] : [])))];
    return keys
      .map((key) => ({ value: key, label: lookup.biomarkerName(key) }))
      .sort((a, b) => a.label.localeCompare(b.label));
  }, [notes, lookup]);

  const visible = useMemo(
    () => filterNotes(notes, { searchTerm, startDate, endDate, biomarkerKey, tag }),
    [notes, searchTerm, startDate, endDate, biomarkerKey, tag]
  );

  const open = (attachment: NoteAttachment) => {
    if (attachment.kind === 'lab-result') onOpenLabResult(attachment.labResultId);
    else if (attachment.kind === 'measurement') onOpenTrend(attachment.biomarkerKey, attachment.date);
    else if (attachment.kind === 'biomarker') onOpenTrend(attachment.biomarkerKey);
  };

  if (isLoading) {
    return (
      <Center h="50vh">
        <Loader aria-label="Loading notes" />
      </Center>
    );
  }

  return (
    <Stack gap="md">
      <Group gap="xs">
        <IconNotes size={24} />
        <Title order={2}>Notes</Title>
      </Group>

      {notes.length === 0 ? (
        <Text c="dimmed">No notes yet. Add notes to a lab result in the Timeline or to a biomarker in Trends.</Text>
      ) : (
        <>
          <SimpleGrid cols={{ base: 1, sm: 2, md: 5 }}>
            <TextInput
              aria-label="Search notes"
              placeholder="Search notes"
              leftSection={<IconSearch size={14} />}
              value={searchTerm}
              onChange={(event) => setSearchTerm(event.currentTarget.value)}
            />
            <DatePickerInput aria-label="Notes from date" placeholder="From" value={startDate} onChange={(value) => setStartDate(value ? new Date(value) : null)} clearable />
            <DatePickerInput aria-label="Notes to date" placeholder="To" value={endDate} onChange={(value) => setEndDate(value ? new Date(value) : null)} clearable />
            <Select aria-label="Filter notes by biomarker" placeholder="All biomarkers" data={biomarkerOptions} value={biomarkerKey} onChange={setBiomarkerKey} clearable searchable />
            <Select aria-label="Filter notes by tag" placeholder="All tags" data={allTags} value={tag} onChange={setTag} clearable searchable />
          </SimpleGrid>

          <Text size="sm" c="dimmed" aria-live="polite">
            {visible.length} {visible.length === 1 ? 'note' : 'notes'}
          </Text>

          {visible.length === 0 ? (
            <Text c="dimmed">No notes match these filters</Text>
          ) : (
            visible.map((note) => {
              const attachment = describeNoteAttachment(note, lookup);
              return (
                <Paper key={note.id} component="article" p="sm" withBorder aria-label={`Note attached to ${attachment.label}`}>
                  <Stack gap="xs">
                    <Group justify="space-between" wrap="nowrap">
                      {attachment.kind === 'none' ? (
                        <Text size="sm" fw={500}>
                          {attachment.label}
                        </Text>
                      ) : (
                        <Button variant="subtle" size="compact-sm" px={0} onClick={() => open(attachment)}>
                          {attachment.label}
                        </Button>
                      )}
                      <RelativeTime date={note.createdAt} />
                    </Group>
                    <NoteContent content={note.content} highlight={searchTerm} />
                    {note.tags.length > 0 && (
                      <Group gap="xs">
                        {note.tags.map((t) => (
                          <Badge key={t} size="xs" variant="light">
                            {t}
                          </Badge>
                        ))}
                      </Group>
                    )}
                  </Stack>
                </Paper>
              );
            })
          )}
        </>
      )}
    </Stack>
  );
}
```
