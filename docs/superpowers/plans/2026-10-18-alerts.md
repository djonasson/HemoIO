# Alerts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the alerts described in `features/alerts.feature` real. That means an Alerts view and a nav item with a badge, severity that is separate from direction, and the messages the Gherkin specifies. Acknowledgements persist. Clicking an alert opens Trends with that data point highlighted.

**Architecture:**
- **Pure rules** in `src/services/alerts/alertRules.ts`: severity, trend detection, timeframe, messages and colours.
- **`useAlerts`** builds alerts from lab results with those rules.
- **Acknowledge and dismiss state** lives in one `AlertStateProvider`, so the nav badge, the Alerts view and Trends agree. Acknowledgements persist in the encrypted user preferences.
- **`AppShell`** owns cross-view navigation: alert → Trends with a focus.

**Tech Stack:** React 19, Mantine 7, Recharts, Dexie (via `EncryptedDb`), Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-gherkin-completion-design.md`, section 2 "Alerts"

## Global Constraints

- **Indicator colour shows direction:** high is `red` (Mantine red-6, `rgb(250, 82, 82)`), low is `orange` (orange-6, `rgb(253, 126, 20)`), an improvement is `green`. A trend is red when increasing and orange when decreasing.
- **Severity:**
  - **Critical** when the value is ≥ 50% beyond the nearest bound. Example: glucose 150 against a high of 100 is +50%, so Critical.
  - Otherwise **Warning**.
  - Improvements are `positive`.
  - There is no `info` level for alerts.
- **Sort order:** Critical, then Warning, then positive; within a severity, most recent first.
- **Messages (exact):**
  - Out of range: `{Name} is high at {value} {unit} (reference {low} - {high} {unit})`, with `is low at` for low values. The range uses a spaced hyphen. With one bound only: `≤ {high}` or `≥ {low}`.
  - Trend: `Consistently increasing over {n} months ({Mon}–{Mon} {Year})` or `Consistently decreasing …`.
  - Improvement: `Improved: {Name} now within range`.
- **Trend alerts:** at least 4 consecutive values, ending with the latest, each strictly lower (or strictly higher) than the one before.
- **Dismiss** hides an alert until the next page load (in memory only).
- **Acknowledge** hides every alert of that biomarker dated on or before the acknowledged alert's date. It is persisted in `userPreferences.acknowledgedAlerts` as `{ [biomarkerKey]: ISO date }`.
- **Relative times:** "Today", "Yesterday", "N days ago", "N weeks ago", "N months ago", "N years ago". The full date (`toLocaleDateString()`) appears in a tooltip on hover.
- **Alert cards:**
  - `role="article"`, accessible name `Alert for {Name}: {severity}, {status/direction}. {message}`.
  - Keyboard: Tab to focus, Enter or Space opens Trends.
- **No unexpected console output in tests.** Every quality gate passes when this plan is done: build, lint, unit tests, and the alerts E2E spec in both browsers.

## Review Focus

1. **Two abnormal values for one biomarker in the same lab result** (duplicates kept after review). The alerts must have unique IDs, so dismissing one must not dismiss both. Pinned in Task 4.
2. **A reference range with only one bound** (e.g. LDL "< 100"). The severity uses that bound, and the message shows `≤ 100` without crashing. Pinned in Task 2.
3. **Importing an older abnormal result after acknowledging.** It stays hidden; a newer one reappears. Pinned in Task 4.
4. **Acknowledging in the Alerts view updates the nav badge at once**, because both use the same state. Pinned in Task 3.
5. **A plateau (two equal consecutive values)** is not a "consistent" trend. Pinned in Task 2.

```ts
/**
 * Human-readable time since a date: "Today", "3 days ago", "2 months ago"
 */
export function formatRelativeTime(date: Date, now: Date = new Date()): string {
  const diffDays = Math.max(0, Math.floor((now.getTime() - date.getTime()) / 86_400_000));

  if (diffDays === 0) return 'Today';
  if (diffDays === 1) return 'Yesterday';
  if (diffDays < 7) return `${diffDays} days ago`;
  if (diffDays < 30) {
    const weeks = Math.floor(diffDays / 7);
    return `${weeks} ${weeks === 1 ? 'week' : 'weeks'} ago`;
  }
  if (diffDays < 365) {
    const months = Math.floor(diffDays / 30);
    return `${months} ${months === 1 ? 'month' : 'months'} ago`;
  }
  const years = Math.floor(diffDays / 365);
  return `${years} ${years === 1 ? 'year' : 'years'} ago`;
}
```

```ts
/**
 * Alert rules: pure functions deciding severity, trends, wording and colour.
 */

export type AlertSeverity = 'critical' | 'warning' | 'positive';
export type TrendDirection = 'increasing' | 'decreasing';

export interface ReferenceRange {
  low?: number;
  high?: number;
}

export const SEVERITY_ORDER: Record<AlertSeverity, number> = { critical: 0, warning: 1, positive: 2 };

/** Fraction beyond the nearest bound at which a value becomes critical */
const CRITICAL_DEVIATION = 0.5;
/** Consecutive same-direction values needed for a trend alert */
const MIN_TREND_VALUES = 4;

export function outOfRangeSeverity(
  value: number,
  status: 'high' | 'low',
  range?: ReferenceRange
): 'critical' | 'warning' {
  const bound = status === 'high' ? range?.high : range?.low;
  if (bound === undefined || bound === 0) return 'warning';
  const deviation = Math.abs(value - bound) / Math.abs(bound);
  return deviation >= CRITICAL_DEVIATION ? 'critical' : 'warning';
}

export function detectConsistentDirection(
  points: Array<{ date: Date; value: number }>
): { direction: TrendDirection; count: number; start: Date; end: Date } | null {
  const sorted = [...points].sort((a, b) => a.date.getTime() - b.date.getTime());
  if (sorted.length < MIN_TREND_VALUES) return null;

  const last = sorted.length - 1;
  const step = Math.sign(sorted[last].value - sorted[last - 1].value);
  if (step === 0) return null;

  let first = last - 1;
  while (first > 0 && Math.sign(sorted[first].value - sorted[first - 1].value) === step) {
    first--;
  }
  const count = last - first + 1;
  if (count < MIN_TREND_VALUES) return null;

  return {
    direction: step > 0 ? 'increasing' : 'decreasing',
    count,
    start: sorted[first].date,
    end: sorted[last].date,
  };
}

const MONTH = new Intl.DateTimeFormat('en-US', { month: 'short' });

export function formatTimeframe(start: Date, end: Date): string {
  const months =
    (end.getFullYear() - start.getFullYear()) * 12 + (end.getMonth() - start.getMonth());
  const span =
    months >= 1
      ? `${months} ${months === 1 ? 'month' : 'months'}`
      : `${Math.max(1, Math.round((end.getTime() - start.getTime()) / 86_400_000))} days`;

  const sameYear = start.getFullYear() === end.getFullYear();
  const sameMonth = sameYear && start.getMonth() === end.getMonth();
  const label = sameMonth
    ? `${MONTH.format(start)} ${start.getFullYear()}`
    : sameYear
      ? `${MONTH.format(start)}–${MONTH.format(end)} ${end.getFullYear()}`
      : `${MONTH.format(start)} ${start.getFullYear()}–${MONTH.format(end)} ${end.getFullYear()}`;

  return `over ${span} (${label})`;
}

export function formatReferenceRange(range: ReferenceRange | undefined, unit: string): string | null {
  if (range?.low !== undefined && range.high !== undefined) return `${range.low} - ${range.high} ${unit}`;
  if (range?.high !== undefined) return `≤ ${range.high} ${unit}`;
  if (range?.low !== undefined) return `≥ ${range.low} ${unit}`;
  return null;
}

export function outOfRangeMessage(
  name: string,
  status: 'high' | 'low',
  value: number,
  unit: string,
  range?: ReferenceRange
): string {
  const reference = formatReferenceRange(range, unit);
  const base = `${name} is ${status} at ${value} ${unit}`;
  return reference ? `${base} (reference ${reference})` : base;
}

export function trendMessage(direction: TrendDirection, start: Date, end: Date): string {
  return `Consistently ${direction} ${formatTimeframe(start, end)}`;
}

export function improvementMessage(name: string): string {
  return `Improved: ${name} now within range`;
}

export function indicatorColor(alert: {
  type: 'out_of_range' | 'trend' | 'improvement';
  status: string;
  direction?: TrendDirection;
}): 'red' | 'orange' | 'green' {
  if (alert.type === 'improvement') return 'green';
  if (alert.type === 'trend') return alert.direction === 'increasing' ? 'red' : 'orange';
  return alert.status === 'high' ? 'red' : 'orange';
}
```

```ts
import { createContext, useContext } from 'react';

export interface AlertState {
  /** Per biomarker: alerts dated on or before this are acknowledged */
  acknowledgedThrough: Record<string, Date>;
  /** Alerts hidden until the next page load */
  dismissedIds: ReadonlySet<string>;
  acknowledge(biomarkerKey: string, through: Date): Promise<void>;
  dismiss(alertId: string): void;
}

export const AlertStateContext = createContext<AlertState | null>(null);

export function useAlertState(): AlertState {
  const context = useContext(AlertStateContext);
  if (!context) {
    throw new Error('useAlertState must be used within an AlertStateProvider');
  }
  return context;
}
```

```tsx
/**
 * Alert State Context
 *
 * Acknowledgements persist in the encrypted user preferences; dismissals
 * last for the page load. One provider keeps the nav badge, the Alerts view
 * and Trends consistent.
 */
import { useCallback, useEffect, useMemo, useState, type ReactNode } from 'react';
import { useEncryptedDb } from '@hooks/useEncryptedDb';
import { AlertStateContext, type AlertState } from '@hooks/useAlertState';

function toDates(stored: Record<string, string> | undefined): Record<string, Date> {
  return Object.fromEntries(Object.entries(stored ?? {}).map(([key, iso]) => [key, new Date(iso)]));
}

export function AlertStateProvider({ children }: { children: ReactNode }): ReactNode {
  const { db, isReady } = useEncryptedDb();
  const [acknowledgedThrough, setAcknowledgedThrough] = useState<Record<string, Date>>({});
  const [dismissedIds, setDismissedIds] = useState<ReadonlySet<string>>(new Set());

  useEffect(() => {
    if (!db || !isReady) return;
    let cancelled = false;
    db.getPreferences()
      .then((prefs) => {
        if (!cancelled) setAcknowledgedThrough(toDates(prefs?.acknowledgedAlerts));
      })
      .catch(() => console.error('Failed to load alert acknowledgements'));
    return () => {
      cancelled = true;
    };
  }, [db, isReady]);

  const acknowledge = useCallback(
    async (biomarkerKey: string, through: Date) => {
      setAcknowledgedThrough((prev) => ({ ...prev, [biomarkerKey]: through }));
      if (!db || !isReady) return;
      const prefs = await db.getPreferences();
      await db.savePreferences({
        unitPreferences: prefs?.unitPreferences ?? {},
        personalTargets: prefs?.personalTargets ?? {},
        theme: prefs?.theme ?? 'system',
        dateFormat: prefs?.dateFormat ?? 'MM/DD/YYYY',
        acknowledgedAlerts: { ...prefs?.acknowledgedAlerts, [biomarkerKey]: through.toISOString() },
      });
    },
    [db, isReady]
  );

  const dismiss = useCallback((alertId: string) => {
    setDismissedIds((prev) => new Set([...prev, alertId]));
  }, []);

  const value = useMemo<AlertState>(
    () => ({ acknowledgedThrough, dismissedIds, acknowledge, dismiss }),
    [acknowledgedThrough, dismissedIds, acknowledge, dismiss]
  );

  return <AlertStateContext.Provider value={value}>{children}</AlertStateContext.Provider>;
}
```
